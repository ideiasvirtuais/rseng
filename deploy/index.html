Enviar o site por FTP para a KingHost — uma das opções.

Passo a passo

Do teste de conexão ao site no ar.

Checklist de publicação
0%
  1. 1. Testar a conexão

    Valida host, usuário e acesso a /www sem enviar nenhum arquivo.

    node scripts/test-ftp-connection.mjs
  2. 2. Gerar o build estático

    Compila SPA + prerender (home, segmentos, obras, health) e gera .htaccess em dist/client/.

    npm run build:ftp
  3. 3. Validar o pacote

    Confere _shell.html, index.html, rotas prerenderizadas, .htaccess e assets.

    node scripts/preflight-ftp.mjs
  4. 4. Simular o envio

    Lista o que seria enviado/removido comparando checksums com o manifesto remoto.

    node scripts/deploy-ftp.mjs -- --dry-run
  5. 5. Publicar

    Envia dist/client/ para /www e remove obsoletos da allowlist. Log em dist/deploy-ftp.log.

    node scripts/deploy-ftp.mjs -- --delete

O deploy usa manifesto SHA-256 no servidor: arquivos idênticos são pulados automaticamente. Use --dry-run para simular e --delete para remover obsoletos. Relatórios completos ficam em dist/deploy-report.md e dist/deploy-ftp.log.
